## 1. 什么是网站风险监控？

网站风险监控是指持续检测网站运行状态和访问风险，包括网站是否能打开、响应是否超时、状态码是否异常、SSL 证书是否即将过期、域名是否存在异常跳转、页面内容是否异常等。

对于长期运营的网站来说，网站风险监控可以帮助站长和团队更早发现问题，减少人工巡检成本。

---

## 2. 网站能打开，为什么还需要监控？

网站能打开，并不代表网站一直正常。

常见情况包括：

* 某些地区打不开
* 某些网络线路访问异常
* SSL 证书快过期
* 页面内容出现错误
* 域名发生异常跳转
* 网站被提示存在风险
* 响应速度变慢
* 支付页或落地页异常

这些问题如果没有自动监控，往往要等用户反馈后才会被发现。

---

## 3. 什么是网站存活检测？

网站存活检测主要用于判断网站是否可以正常访问。

通常会检测：

* HTTP 状态码
* 网站响应时间
* 是否访问超时
* 是否出现服务器错误
* HTTPS 是否正常连接
* 页面是否返回正常内容

风控哨兵支持网站存活检测，可以帮助用户及时发现网站打不开、超时和宕机问题。

---

## 4. SSL 证书为什么需要提前提醒？

SSL 证书过期后，浏览器可能会提示网站不安全，用户也可能无法正常访问 HTTPS 页面。

这会影响：

* 用户信任
* 登录注册
* 在线支付
* 广告落地页转化
* 企业官网形象
* 搜索引擎体验

风控哨兵支持 SSL 证书到期提醒，可以帮助用户提前发现证书过期风险。

---

## 5. 什么是域名劫持检测？

域名劫持检测主要用于发现域名访问异常、异常跳转、解析异常或疑似 DNS 污染等问题。

常见表现包括：

* 域名跳转到陌生页面
* 不同地区访问结果不同
* 页面内容和原网站不一致
* 域名解析到异常 IP
* 某些线路无法访问
* 用户访问到了错误页面

对于跨境业务、广告落地页和高风险站点来说，域名劫持检测非常重要。

---

## 6. DNS 污染检测有什么作用？

DNS 污染或 DNS 解析异常，可能导致用户无法正确访问网站。

即使服务器本身正常，只要 DNS 解析出现问题，用户依然可能遇到网站打不开、跳转异常或访问结果不一致的情况。

风控哨兵可以结合域名异常检测、网站存活检测和 Telegram 告警，帮助用户及时发现这类风险。

## 7. 页面关键词监控适合检测什么？

页面关键词监控适合检测网站页面中的异常内容。

例如：

* 维护中
* 系统错误
* 页面不存在
* 访问异常
* 服务器错误
* 暂停服务
* 风险提示
* 无法访问

有些网站状态码正常，但页面内容已经异常。页面关键词监控可以帮助用户发现这种隐藏问题。
