## 为什么需要页面关键词监控？

网站能打开，不代表页面内容一定正常。

常见情况包括：

* 页面显示“维护中”
* 页面显示“系统错误”
* 页面出现“访问异常”
* 页面变成空白页
* 页面内容被替换
* 页面跳转到错误页面
* 页面提示服务器错误
* 支付页或落地页内容加载异常

这些问题往往不会直接表现为网站宕机，但同样会影响用户访问和业务转化。
