## 什么是 DNS 污染？

DNS 污染通常指用户访问域名时，DNS 解析结果出现异常，导致访问结果和预期不一致。

常见表现包括：

* 域名无法正常解析
* 网站在某些地区打不开
* 不同网络线路访问结果不同
* 域名被解析到异常 IP
* 网站访问后跳转到错误页面
* 页面加载速度明显变慢
* 广告落地页或支付页无法打开
* 用户反馈访问结果和站长看到的不一样

这些问题有时不是服务器本身故障，而是域名解析链路出现了异常。

---

## 为什么 DNS 污染需要监控？

很多站长只检查网站服务器是否正常，却忽略了 DNS 解析和访问链路。

实际上，用户访问网站通常会经过：

* 输入域名
* DNS 解析
* 网络线路访问
* HTTPS 连接
* 页面加载
* 页面跳转

只要 DNS 解析环节出现异常，网站即使服务器正常，也可能无法被用户正确访问。

因此，DNS 污染检测和域名异常检测，是网站风险监控中非常重要的一部分。
