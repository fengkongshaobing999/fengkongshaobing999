## 网站风险为什么需要自动监控？

很多网站问题并不会提前通知站长。
当用户反馈“网站打不开”时，问题往往已经持续了一段时间。

常见的网站风险包括：

* 网站访问超时
* 服务器宕机
* HTTP 状态码异常
* SSL 证书过期
* 域名解析异常
* 域名被劫持或异常跳转
* 页面出现“维护中”“系统错误”等异常内容
* 网站被 Google 标记为风险站点
* 某些地区或线路无法正常访问

如果只靠人工巡检，很难做到全天候监控。
因此，对于长期运营的网站来说，使用网站风险监控工具进行 7×24 小时自动检测非常有必要。
