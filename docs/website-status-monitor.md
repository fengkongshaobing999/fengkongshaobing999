## 什么是网站存活检测？

网站存活检测，就是定期检查网站是否可以正常访问。

常见检测内容包括：

* 网站是否能打开
* HTTP 状态码是否正常
* 网站响应时间是否过长
* 是否出现访问超时
* 是否出现服务器错误
* HTTPS 是否正常连接
* 页面是否正常返回内容

通过自动化网站存活检测，可以减少人工巡检成本，也能更早发现网站异常。

## 常见的网站异常类型

风控哨兵可以帮助用户关注多种网站访问异常：

### 1. 网站访问超时

当网站响应时间过长或请求无法完成时，可能说明服务器、网络线路或域名访问存在问题。

### 2. HTTP 状态码异常

例如 403、404、500、502、503 等状态码，都可能代表页面无法正常访问或服务器出现异常。

### 3. 网站宕机

当网站完全无法打开时，系统需要第一时间推送告警，方便运维人员及时处理。

### 4. HTTPS 访问异常

如果 HTTPS 连接失败，可能和 SSL 证书、服务器配置或网络访问有关。

### 5. 页面内容异常

有些网站虽然能打开，但页面内容已经出现错误，需要结合页面关键词监控一起判断。
